# v4.4: Исправление багов и доработка UI

Полный анализ и план: `docs/v4_tz.md`

## Корневая проблема
Статический HTML содержит 19 `fetch()` вызовов к API. В статическом режиме сервера нет → dashboard, risk severity, services, MITRE, топологии падают с ошибками. Решение: инжектить все данные на этапе генерации + флаг `STATIC_MODE`.

## 14 багов:

### #1 — Курсор залипает после клика на карту
**Причина:** physics в vis-network не отключается после drag.
**Статус:** 🔴 не исправлено

### #2 — Нет панели настроек (физика и др.)
**Причина:** Нужна отдельная кнопка/панель.
**Что добавить:** физика on/off, тема, размер узлов, показ меток, сброс.
**Статус:** 🔴 не исправлено

### #3 — Переключение режимов Standard/Hierarchy/Circle/Risk/Attack
**Причина:** `setMode()` вызывает `setOptions()` но vis-network может игнорировать.
**План:** добавить `network.redraw()`, проверить атрибуты кнопок.
**Статус:** 🔴 не исправлено

### #4 — Переключение 2D ↔ 3D
**Причина:** При возврате в 2D canvas разрушен, default стоит 3D.
**План:** починить `toggle3D()`, сделать 2D по умолчанию.
**Статус:** 🔴 не исправлено

### #5 — Экспорт PNG + удаление SIEM
**Причина:** PNG-экспорт сломан, SIEM не нужен.
**План:** html2canvas для PNG, убрать SIEM из UI.
**Статус:** 🔴 не исправлено

### #6 — Топологии не работают (все 7)
**Причина:** `fetch()` к API в статике, модули могут возвращать пустые данные.
**План:** инжектить топологии в HTML, проверить каждый модуль.
**Статус:** 🔴 не исправлено

### #7 — Счётчик nodes/edges/rules/issues
**Причина:** `updateStats()` не вызывается или данные не доходят.
**План:** читать из `allNodes.length` и т.д., вызывать после загрузки.
**Статус:** 🔴 не исправлено

### #8 — Дашборд — «TypeError: Failed to fetch»
**Причина:** `fetch('/api/dashboard')` в статическом режиме.
**План:** инжектить `__DASHBOARD_JSON__` + проверка `STATIC_MODE`.
**Статус:** 🔴 не исправлено

### #9 — Risk Severity — пустой
**Причина:** `fetch('/api/risk-severity')`.
**План:** инжектить `__RISK_SEVERITY_JSON__` + `STATIC_MODE`.
**Статус:** 🔴 не исправлено

### #10 — Top Services — пустой
**Причина:** `fetch('/api/services')`.
**План:** инжектить `__SERVICES_JSON__` + `STATIC_MODE`.
**Статус:** 🔴 не исправлено

### #11 — Поиск в подменю «Правила»
**Причина:** Нет поля поиска над таблицей правил.
**План:** добавить input + фильтр по всем полям + debounce.
**Статус:** 🔴 не исправлено

### #12 — Подменю «Аудит» пустое
**Причина:** Данные инжектятся но renderAudit() может не отображать.
**План:** проверить формат данных, поправить рендеринг.
**Статус:** 🔴 не исправлено

### #13 — Связанные правила в подменю «Инфо»
**Причина:** `showNodeInfo()` показывает только базовую инфу без правил.
**План:** найти рёбра узла → извлечь правила → показать список.
**Статус:** 🔴 не исправлено

### #14 — MITRE — пустое подменю
**Причина:** `fetch('/api/mitre/matrix')` в статике.
**План:** инжектить `__MITRE_JSON__` + `STATIC_MODE`, улучшить маппинг.
**Статус:** 🔴 не исправлено
